## 🚀 SIMPLE 2-STEP INTEGRATION

### Step 1: Add Scripts to index.html

Open `index.html` and find this section (around line 2793-2795):

```html
    <script src="assets/dist/js/bundle.min.js"></script>
<script src="assets/js/utils.js"></script>
    <script src="assets/js/purchase-orders.js"></script>
```

**Replace with:**

```html
    <script src="assets/dist/js/bundle.min.js"></script>
<script src="assets/js/utils.js"></script>
    <!-- RBAC System -->
    <script src="assets/js/rbac-helper.js"></script>
    <script src="assets/js/rbac-init.js"></script>
    <!-- End RBAC System -->
    <script src="assets/js/purchase-orders.js"></script>
```

### Step 2: Test It!

That's it! The `rbac-init.js` file will automatically:
- Intercept user login
- Migrate old permissions to new system
- Apply permissions to UI elements
- Hide/show menu items based on roles

## 🔧 How It Works

The `rbac-init.js` file automatically:

1. **Intercepts user storage** - When a user logs in, it captures the user data
2. **Migrates permissions** - Converts old `perm_*` fields to new `allPermissions` array
3. **Applies to UI** - Hides/shows menu items based on permissions:
   - `.p_one` - Products
   - `.p_two` - Categories
   - `.p_manufacturers` - Manufacturers
   - `.p_suppliers` - Suppliers
   - `.p_three` - Transactions
   - `.p_four` - Users
   - `.p_five` - Settings

4. **Adds role badge** - Shows user role next to username

## 🎯 Custom Permissions

Grant specific permissions beyond role:

```javascript
// Example: Give cashier discount permission
fetch('http://localhost:3000/api/users/user/USER_ID/permissions', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    customPermissions: ['pos.apply_discount', 'pos.void_transaction']
  })
}).then(r => r.json()).then(console.log);
```

## 🐛 Troubleshooting

### Issue: Menu items not hiding
**Solution:** Check browser console for `[RBAC]` messages. Make sure scripts loaded in correct order.

### Issue: User has wrong permissions
**Solution:** Check user object in console:
```javascript
console.log(user);
console.log(user.allPermissions);
```

### Issue: Login not working
**Solution:** Check API response includes `allPermissions` array:
```javascript
// In Network tab, check /api/users/login response
```
